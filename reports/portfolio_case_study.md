# Case Study: Social Media Analytics Engine

## Business Goal

Help a brand, creator, or agency understand social media performance across platforms, topics, content types, and sentiment.

## Workflow

1. Generate a privacy-safe demo post dataset.
2. Score sentiment using an explainable lexicon.
3. Store data in SQLite.
4. Run SQL portfolio queries for platform, topic, and sentiment performance.
5. Export CSV tables and a client-ready dashboard.

## Analyst Value

This project shows practical Python automation, SQL analytics, sentiment analysis, KPI reporting, and dashboard delivery.
